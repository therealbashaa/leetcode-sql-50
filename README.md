## 📈 Learning Approach

For every problem, I try to understand:

1. What is the business requirement?
2. Which SQL concepts solve the problem?
3. Can the query be written in a simpler or more efficient way?
4. What edge cases should be considered?
5. What did I learn from the solution?

This approach helps me move beyond memorizing queries and build practical SQL skills.
